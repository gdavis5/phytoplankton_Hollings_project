# Phytoplankton Phenology Hollings Project
<br>This project focuses on defining phytoplankton blooms for the Northeast US Continental Shelf and quantifying bloom metrics.
<br>We first define phyotplankton blooms using a threshold and rate of change method. Using that definition, we quantify a variety of individual and regional bloom metrics. The final step was visualizing these metrics to track phenology changes.
<br>This project was done as a part of National Marine Fisheries Service Northeast Fisheries Science Center
<br>Funding for this project is from the Ernest F. Hollings Undergraduate Scholarship Program.
